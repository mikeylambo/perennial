# Perennial

A quiet paper-cut roguelite: descend a mountain through autumn and winter, bury what you love in its plots before the guardian, and climb back up in spring on what it grew into.

This is the **Phase 0 thesis proof** (GDD §40): one face of Emberfell (four autumn rooms, three winter rooms, the Drift Floor), Folio's paper moves, four keepsakes and two scrap, plots, growth, rot, the turn, landmarks, harvest and the Drift Wolf, over three years. No hub, no meta.

```bash
npm install
npm run dev        # play at http://localhost:5173
npm run gates      # typecheck, tests, climb bot, build, end-to-end smoke
```

Controls: A/D run · Space jump (hold to glide) · Shift slide · J/K/L keepsakes · tap E take · hold E bury (1/2/3 picks the slot) · Esc pause. Gamepad and touch are supported.

Design: `docs/GDD.md` (source of truth). Builder law: `CLAUDE.md`. Decisions: `DECISIONS.md`.
